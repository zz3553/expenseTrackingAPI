# Expense Tracking API

Project Description URL: https://roadmap.sh/projects/expense-tracker-api

Technologies:
- Python
- FastAPI

Running the Application:
- Install fastapi
  - `pip install "fastapi[standard]"`
- Run app
  - `source .venv/bin/activate`
  - `fastapi dev main.py`
  - `uvicorn main:app --reload --log-level debug` # Running with debug mode
  
- API Docs
  - http://127.0.0.1:8000/docs
  - http://127.0.0.1:8000/redoc
